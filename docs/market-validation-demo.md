# Market Validation Demo

Use this artifact to record the 30-second before/after demo for the paid beta.
Keep the story narrow: Mac screen recordings in, smaller local MP4 out,
original unchanged.

## Default Variant

`Work Screen Recordings`

## Required Proof In The Demo

1. The input is a Mac screen recording.
2. DropSquash runs locally on Mac.
3. The output is smaller.
4. The original stays available.
5. No upload or account step appears.

## Shot List

| Time | Shot | What to show |
|---|---|---|
| 0:00-0:04 | Problem | Finder shows one large screen recording and its size |
| 0:04-0:08 | App start | DropSquash window already open and calm, with no extra panels |
| 0:08-0:12 | Input | Drag the recording onto DropSquash |
| 0:12-0:18 | Conversion | Progress bar advances; no upload, login, or export settings hunt |
| 0:18-0:23 | Result | Finder reveals the new `.squashed.mp4` file |
| 0:23-0:27 | Before/after | Original and output sizes are both visible side by side |
| 0:27-0:30 | Trust close | Original file still exists; local-first message or privacy receipt may be visible if already part of the flow |

## Recording Rules

- Record on macOS with the packaged app, not a dev-only surface.
- Use one real screen recording that actually becomes smaller.
- Avoid cuts that hide waiting, file reveal, or original preservation.
- Do not claim hardware encoding, metadata removal, or upload behavior beyond
  what the product proves on screen.

## Success Check

- The viewer can explain the job in one sentence:
  `Drop a Mac screen recording and get a smaller MP4 locally.`
- The smaller output is visible, not only narrated.
- The unchanged original is visible, not only implied.
