FAQ

Does DropSquash upload my videos?

No. DropSquash does not upload media for compression. Video compression runs locally on your computer.

Does it delete originals?

No. Originals are kept by default. Cleanup only moves originals to Trash after a successful verified conversion.

Does a failed conversion count?

No. Failed, cancelled, or not-smaller conversions do not count toward the current 20-conversion beta trial.

What is supported right now?

The current public surface is macOS only: a single-file local post-processing path for MOV, MP4, and M4V screen recordings that become smaller MP4 outputs.

Does it use command-line media tools?

No. The product media path does not shell out to command-line media tools.

What is a privacy receipt?

When enabled, DropSquash writes a local JSON receipt next to the output file with uploaded_bytes = 0, metadata_policy = preserve, and file names instead of absolute paths.

Where is the refund policy?

The refund policy draft is published for review before checkout goes live.

Where are the product-use terms?

The draft Terms of Service are published separately from the license policy.

Conversion help

For a conversion issue, include the app version, macOS version, input file type, approximate original size, selected profile, selected output size, and the exact error text.

Contact support through GitHub Issues until the paid beta support address is published.

Do not send screen recordings in the first message. Share media only after removing private content and only if support explicitly asks for a sample.
